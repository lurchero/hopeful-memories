# App Flow — Hopeful Memories

## Site Type
Single-page marketing site with anchor navigation (Phase 1).
Multi-page structure planned for Phase 2.

## Navigation Flow
```
[Navbar — fixed]
  Logo | Mission | Programs | Impact | Gallery | Get Involved | Donate

[Hero]  ← Landing point
  ↓ Scroll or CTA
[Mission]  #mission
  ↓
[Programs]  #programs
  ↓
[Impact]  #impact
  ↓
[Gallery]  #gallery
  ↓
[Get Involved]  #get-involved
  ↓
[Donate]  #donate
  ↓
[Contact + Newsletter]  #contact
  ↓
[Footer]
```

## Section-by-Section Flow

### 1. Navbar
- Fixed top, transparent → solid on scroll
- Logo (placeholder) + anchor links
- Mobile: hamburger → slide-down menu
- "Donate" button always visible (accent color)
- Smooth scroll to anchors

### 2. Hero
- Full-width, photography-driven
- Headline: "Capturing Memories. Honoring Lives."
- Subtext explaining the mission
- Two CTAs: "Donate" (filled) + "Get Involved" (outline)
- Background: hero photograph or subtle warm gradient

### 3. Mission / Philosophy
- Why Hopeful Memories exists
- Short, grounded copy about dignified storytelling
- Possibly a pull quote or emphasis block
- Background: light (secondary)

### 4. Programs
- 4–5 program cards in a grid
- Each card: title + short description
- Programs: Family Portraits, Creative Workforce, Youth Mentorship, Community Storytelling, Corporate Partnerships
- Background: warm

### 5. Impact
- Key statistics in a bold, scannable layout
- Metrics: families served, photographers paid, events held, etc.
- Partner/supporter names or logos (if available)
- Background: dark

### 6. Gallery
- Photography showcase from real programs
- Gallery wall aesthetic (framed pieces with accent lighting)
- 6+ pieces in responsive grid
- Background: dark (neutral-900)

### 7. Get Involved
- Three pathways: Donate, Apply (photographers), Partner (corporate)
- Each pathway: icon/visual + short description + CTA
- Background: light

### 8. Donate
- Dedicated section reinforcing the donation ask
- Emotional but dignified copy
- Clear, prominent "Donate" CTA
- Background: warm or accent-tinted

### 9. Contact + Newsletter
- Contact form: name, email, message
- Newsletter signup: email + subscribe
- Netlify Forms integration
- Background: dark

### 10. Footer
- Logo (placeholder)
- Navigation links
- Social media links
- Legal: copyright, privacy policy link
- Background: darkest (neutral-900)

## User Journeys

### Donor Journey
Hero → Impact (see the numbers) → Donate section → Complete donation

### Creative/Photographer Journey
Hero → Programs (see opportunities) → Get Involved (apply) → Contact

### Partner/Corporate Journey
Hero → Mission → Programs → Impact → Get Involved (partner) → Contact

### General Visitor Journey
Hero → Scroll through all sections → Subscribe to newsletter
